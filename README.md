# Choice Telecom

A React and Vite single-page website for Choice Telecom.

## Technology

- React
- React Router
- Tailwind CSS
- Vite
- JavaScript
- Existing responsive project CSS

## Run locally

```powershell
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```powershell
npm run build
npm run preview
```

The static production output is written to `dist/`.

## Routes

- `/`
- `/products`
- `/products/:id`
- `/offers`
- `/about`
- `/contact`

Product data is in `js/data.js`. Product images are served from `assets/images/products/`.
