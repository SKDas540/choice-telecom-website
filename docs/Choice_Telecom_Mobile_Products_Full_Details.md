## Important notes before using this document

-   Prices change frequently and may vary by official/unofficial status,
    warranty, seller, VAT, color, and stock.
-   Do not copy a market price into Choice Telecom's live website
    without checking the current supplier invoice and shop selling
    price.
-   RAM expansion/Extended RAM is virtual memory using internal storage.
    It is not the same as physical RAM.
-   A model's regional configuration can differ. Confirm the exact
    Bangladesh unit, box label, model code, RAM/storage, charger,
    warranty and network support before listing.
-   **GigaX Y11 4/64** could not be reliably identified from available
    manufacturer or trustworthy product references. It is intentionally
    marked **verification required** rather than inventing
    specifications.
-   **itel A100C Special Edition**: the official A100C specification
    page was found, but the exact "Special Edition" package/finish was
    not independently verified. The standard A100C specs are listed;
    confirm whether the special edition has any hardware difference.
